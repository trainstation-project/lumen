# `lumen/ops/elementwise`

Kernels for the elementwise primitives: `add`, `sub`, `mul`, `div`, `max`,
`eq`, `lt`, `neg`, `exp`, `log`, `sqrt`, `tanh`, `logistic`, `cast` and
`select`. Only an MPS backend exists here; the module is just the `mps/`
submodule, compiled when `lumen_mps_linked` is set.

Callers: graph plan steps on MPS reach [`mps::encode`](mps/mod.rs) through
the primitive dispatch in [`lumen/ops/mps/mod.rs`](../mps/mod.rs). The
reference interpreter (`lumen/ops/reference.rs`) evaluates these primitives
itself. Fused elementwise chains are generated by the graph compiler
(`lumen/graph_compiler/mps`), not by this folder; they share the functors in
`lumen/ops/mps/kernels.metal`.
