# `lumen`

The package root: one Rust crate (`lib.rs`, built as the Python extension
`lumen._native` via `python.rs`) and the Python package around it. lumen is a
JAX/XLA-style tracer and graph compiler with a PyTorch-shaped frontend and
hand-written / generated Metal kernels.

How the pieces fit: everything runs inside `lumen.compile`. The tracer
(`graph/tracer.py`) calls the user's function once per input signature with
`TracedTensor`s, recording primitives (`graph/prims.py`, `functional/`) into a
`Graph`. `autograd/` differentiates that traced tape into more primitives.
`graph_compiler/` rewrites the graph per device (on MPS: fusion into kernels
generated by `codegen/`) and plans its memory into a `Plan`, which runs the
`ops/` kernels on `tensor/` data allocated by `allocator/` and ordered by
`stream/`. A `Tensor` holds data; only the graph computes.

## Layout conventions

* A folder's Rust module is `mod.rs`; Python bindings are `python.rs`
  (behind the `python` feature) registering into `lumen.<folder>._C`; `_C.pyi` stubs
  them; `__init__.py` is the Python-facing package; `tests.rs` holds Rust unit
  tests (Python tests live in the repo's top-level `tests/`).
* Device-specific code is gated on `build.rs` cfgs (`lumen_mps_linked`,
  `lumen_cuda_linked`) so the crate compiles without Metal or CUDA.

## Invariants

* **No eager execution.** Ops, RNG draws and autodiff run only while tracing
  inside `lumen.compile`; they raise otherwise.
* **Exact dtypes.** Programs run as traced: no op changes a dtype the program
  did not ask for. Matmuls carry explicit `accum_dtype` and `output_dtype`
  (`@` infers float32 accumulation for narrower floats).
* **Own kernels.** Graphs run through lumen's `Plan` and its own kernels, not a
  vendor graph runtime.
* **Weights are meta tensors**, placed on a device when a function using them
  compiles and shared by every compiled function on that device.
* Compiler behavior is switched by `lumen.config.compiler.*` flags
  (`graph_compiler/config.rs`), e.g. `flash_attention`, `merge_dots`,
  `fused_linear_cross_entropy_chunk_size`, `safe_kernels` (off by default).
