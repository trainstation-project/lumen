Bandwidth by size

Elementwise ops are memory-bound, so bandwidth is their measure: bytes read and written over device time, float32. The memory roof is the best bandwidth measured at 64M elements, past the GPU's cache. Up to a few million elements the data stays in that cache, so bandwidth there can exceed DRAM's.
